About the Application

Freelancer AutoApply is an independent software project designed to help individual freelancers manage their work more efficiently. It is intended to integrate with Freelancer.com through its official API, subject to authorization and approved API permissions.

The application is not affiliated with or endorsed by Freelancer.com.

Privacy and Security

Access to Freelancer accounts is intended to use OAuth 2.0 authorization. The application will request only the permissions necessary for its features. Users remain in control of account actions. Bids and messages are not submitted automatically without user authorization.
